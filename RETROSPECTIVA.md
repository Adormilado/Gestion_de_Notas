
# Retrospectiva del Proyecto

| Pregunta | Respuesta |
| :--- | :--- |
| **¿Qué funcionó bien?** | El uso del tablero Kanban en GitHub Projects permitió mantener una visión clara de los avances de cada requisito (CRUD) y la integración de Tkinter con JSON se ejecutó de forma limpia y rápida. |
| **¿Qué no funcionó / qué me costo trabajo?** | El manejo de estados en Tkinter al seleccionar elementos del `Listbox` requirió atención extra para evitar sobrescribir notas por error al momento de hacer clic en guardar. |
| **¿Qué haría distinto la próxima vez?** | Implementar pruebas unitarias básicas para validar la lectura/escritura del archivo JSON antes de renderizar la interfaz gráfica, e incluir soporte para Markdown. |
