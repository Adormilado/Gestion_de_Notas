# Interfaz_De_Notas

## Descripción
Elegi 'Notes App' (Tier 1 de App Ideas) porque resuelve la necesidad de crear, editar, eliminar y almacenar notas personales de forma persistente y rápida sin depender de herramientas en la nube, con un alcance adecuado para completarse de forma funcional en el tiempo disponible.

## User Stories
- **Como usuario**, quiero crear una nota con título y contenido para registrar mis pendientes.
- **Como usuario**, quiero seleccionar y editar una nota existente para actualizar su información.
- **Como usuario**, quiero eliminar notas que ya no necesite para mantener mi lista ordenada.
- **Como usuario**, quiero que mis notas se guarden automáticamente para consultarlas al reabrir la aplicación.
- **Como usuario**, quiero ver la fecha de creación de cada nota para llevar un historial temporal.

## Metodología
**Kanban (Enfoque Ágil)** — Se seleccionó esta metodología ágil debido a que el proyecto requiere visualización continua de tareas simples en un flujo de trabajo dinámico (Pendiente, En progreso, Terminado). Kanban minimiza sobrecargas de gestión, permite entregas parciales funcionales y facilita el rastreo directo de los requisitos mediante la herramienta GitHub Projects.
